About the Program

The Bachelor of Science in Computer Science (BSCS) program provides students with knowledge and skills in programming, software development, computer systems and information technology.

Students learn how to create useful applications, solve problems using technology and develop innovative solutions for the future.

Why Choose BSCS?

  • Learn programming and software development
  • Develop problem-solving skills
  • Study web and application development
  • Learn database and computer technologies
  • Prepare for careers in the technology industry

Skills You Can Learn

  1. HTML & CSS
  2. Java Programming
  3. Web Development
  4. Database Management
  5. Problem Solving
  6. Software Development

Career Opportunities

BSCS graduates can pursue different careers in the field of computer science and information technology.

  • Software Developer
  • Web Developer
  • Programmer
  • Database Administrator
  • Systems Analyst
  • IT Specialist
